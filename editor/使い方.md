# nu_log 編集室

## 開く

プロジェクト直下の「エディターを開く.cmd」をダブルクリックします。
起動済みの場合は http://127.0.0.1:4177 をブラウザーで開けます。
パソコンを再起動した後も、同じファイルから起動できます。

## 編集する

1. 左の記事一覧で記事を選びます。
2. 中央で記事タイトル、著者、本文、キャプションを直接編集します。
3. 写真の「幅」「高さの上限」「並べ方」で紙面を調整します。高さを空欄にすると初稿の設定を使います。
4. 項目の↑↓で写真や段落を移動します。「この項目の前で改ページ」で位置を区切れます。
5. 写真をクリックすると取得済み95点から差し替えられます。「写真を並べる」で1ブロックに2点まで置けます。
6. 下のボタンで、選択した項目の後に本文・見出し・写真を追加できます。

写真は縦横比を保ちます。幅は紙面の本文領域に対する比率、高さは上限です。
高さの制限に先に達している画像では、幅を増やしても画像は拡大しません。

## プレビュー

- 「この記事」では選択記事だけをVivliostyleで組版します。ページ番号は1からで、記事開始ページの左右も全冊と異なる場合があります。
- 「全冊」では表紙・目次・すべての記事・裏表紙を表示します。実際の通し番号と記事のつながりはこちらで確認します。
- 自動更新は入力停止から約1.5秒後です。重い場合は外し、「プレビュー更新」を押します。
- プレビュー上部の矢印でページ移動、拡大鏡でズームできます。「大きく開く」で別タブでも確認できます。
- 表紙・裏表紙も左下のボタンから差し替えられます。

## 保存・PDF

- 「保存」または Ctrl+S でローカルファイルへ保存します。
- 「元に戻す」または Ctrl+Z、「やり直す」または Ctrl+Shift+Z が使えます。履歴は画面を開いている間、直近100操作です。
- 未保存の内容はブラウザーにも下書き保存され、再読み込み時に復元できます。正式な保存には「保存」を押してください。
- 「PDFを書き出す」は変更を保存してから全冊を出力します。完成後に「PDFを開く」を押します。
- 出力先は `output/editor/nu_log.pdf`。初稿 `output/pdf/nu_log.pdf` は変更しません。
- PDF出力中は保存を受け付けません。画面上の編集はできるため、出力後に改めて保存してください。

## データと復元

- 編集の正本：`editor/data/book.json`
- 初回起動前のHTML：`editor/data/original-book.html`
- 保存ごとの旧データ：`editor/data/history/`
- 組版HTML：`manuscripts/book.html`

`npm run typeset` は編集の正本から再生成するため、編集内容を保持します。
エディター起動後はHTMLの直接編集ではなく、この編集画面を使ってください。
履歴ファイルから過去の保存状態へ戻す場合はサーバーを止め、対象JSONを `book.json` にコピーして再起動します。
元Google Docsの再取り込みは自動同期されません。初稿素材を保護するため `prepare:source` は編集開始後に停止します。

このエディターはローカル専用です。取得済み画像を扱う版で、新しい画像ファイルのアップロードと自由座標へのドラッグ配置は含みません。
PDFはカラー確認用です。入稿の塗り足し・CMYK変換は別工程です。

### 表紙・裏表紙なしのPDF

画面上部で「表紙・裏表紙なし」を選び、「PDFを書き出す」を押します。目次とすべての記事を残し、ページ番号と目次の参照を組み直します。出力先は `output/editor/nu_log-no-covers.pdf` です。「表紙・裏表紙あり」のPDFとは別に保存されます。

## 章の追加・削除と下書き

- 左下の「＋ 章を追加」からタイトル・著者・目次の分類を指定します。新しい分類も作れます。同じ分類なら選択中の章の直後、それ以外は分類の末尾に追加されます。
- 「選択中の章を削除」で本文と目次から章を外します。確認後も「元に戻す」で取り消せます。「保存」で確定します。最後の1章は削除できません。
- 章の「執筆メモ」は編集画面だけに表示され、プレビューやPDFには掲載されません。
- 「下書き」にした章は記事単独のプレビューで確認できますが、全冊プレビュー・目次・PDFには含まれません。執筆が終わったら下書きを外して保存してください。
